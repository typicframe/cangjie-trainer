# 無障礙倉頡打字練習

三代倉頡練習頁，繁體中文／香港粵語。適合鍵盤操作同螢幕報讀。

## 線上使用

- 倉頡：https://typicframe.github.io/cangjie-trainer/
- 英文打字／冒險：https://typicframe.github.io/cangjie-trainer/typing.html

### Google 協作平台（Sites）

請用「嵌入 → 依網址嵌入」，網址用：

`https://typicframe.github.io/cangjie-trainer/typing-embed.html?v=20261106b`

每次大改之後，喺 Sites 改 `?v=` 後面嘅數字（例如 `?v=20261107`），先至會逼瀏覽器同 Sites 重新載入，唔好貼 HTML 程式碼。

## 本機使用

用瀏覽器打開 `index.html` 或 `倉頡打字練習.html`，一個檔已經包埋字典。
